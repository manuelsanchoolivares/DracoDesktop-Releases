# Draco Desktop releases

Desktop client for the Draco cluster at Friedrich Schiller University Jena.

**Download:** [latest release](https://github.com/manuelsanchoolivares/DracoDesktop-Releases/releases/latest) — run the `DracoDesktop-Setup-…exe` installer (no administrator rights needed).

The first time Draco Desktop opens it asks you to request access; you can use it right away during a 7-day trial while your request is reviewed.

Contact: manuel.sancho.olivares@uni-jena.de
